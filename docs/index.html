主要機能

スマートなグループ化

ドラッグ＆ドロップでアイコンを整理。ウィンドウサイズに合わせて自動で整列する「グリッド・リフロー」方式を採用しています。

高度なカスタマイズ

色、サイズ、透過度（Alt+ドラッグ）などを直感的に調整可能。クリップボードからのコピー＆ペーストでも設定を適用できます。

究極のパフォーマンス

RustとDirectX 11によるネイティブ実装。アイドル時のCPU使用率0%を目指したイベント駆動型設計です。

美しい透過表現

DirectCompositionによるハードウェアアクセラレーション。現代のWindowsにふさわしい高品質な透過描画を実現します。

操作方法

Ctrl + ドラッグ ウィンドウの移動
Shift + ドラッグ ウィンドウのリサイズ
Alt + ドラッグ 背景の透過度調整
Ctrl + V 色やサイズの変更

技術スタック
