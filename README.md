# Fencery

Windows デスクトップのアイコンを「フェンス」と呼ぶグループにまとめて整理するユーティリティ。
Rust 製で、Win32 API と DirectX 11 による軽量な常駐動作とハードウェア加速された透過描画を提供する。

バージョン: 3.0.0 / ライセンス: MIT

## 概要

デスクトップ上にフェンス（グループウィンドウ）を配置し、ファイルやショートカットをドラッグ＆ドロップで格納する。
格納されたアイコンはウィンドウサイズに合わせてグリッド配置され、設定は自動的に永続化される。

設計上の留意点:

- アイドル時の CPU 使用率を最小化するイベント駆動型のメッセージループ。
- DirectComposition による透過合成。背景のみを透過させ、アイコンとラベルは鮮明に描画する。
- ウィンドウごとの状態とグローバルな外観設定を分離した構成。

技術スタック: Rust (edition 2024) / Win32 API / DirectX 11 / Direct2D / DirectWrite / DirectComposition

## 機能

- アイコンのグループ化、ドラッグによる並び替え、ダブルクリックで実行。
- 右クリックでファイルの場所をエクスプローラーで開く。
- 位置、サイズ、背景色、透過度、アイコンサイズの自動保存と復元。
- クリップボード経由での外観変更（色・アイコンサイズ）。

## 操作

| 入力 | 動作 |
| --- | --- |
| 左ドラッグ | アイコンの並び替え |
| `Ctrl` + 左ドラッグ | ウィンドウの移動 |
| `Shift` + 左ドラッグ | ウィンドウのリサイズ |
| `Alt` + 左ドラッグ | 背景の透過度調整 |
| ダブルクリック | アイコンの実行 |
| 右クリック | ファイルの場所を開く |
| `Ctrl` + 右クリック（アイコン上） | アイコンの削除 |
| `Ctrl` + 右クリック（空白部） | グループの削除 |

トレイアイコンのコンテキストメニューからグループを新規作成する。

### クリップボードによる設定変更

値をコピーして `Ctrl` + `V` で適用する。

| 入力例 | 動作 |
| --- | --- |
| `#RRGGBB` / `#RRGGBBAA` | 背景色の変更 |
| `#random` | ランダムな背景色 |
| `size:64` | アイコンサイズの変更（16〜256 px） |

## コマンドライン引数

起動時に外観を指定できる。

```
desktop-grouping.exe --font "Meiryo" --fsize 12
```

| 引数 | 説明 |
| --- | --- |
| `--font <NAME>` | 描画フォントの指定 |
| `--fsize <SIZE>` | フォントサイズの指定 |

## ビルド

要件:

- Rust ツールチェーン（edition 2024 以降）
- Windows SDK（DirectX 関連のビルドに必要）

```
cargo build --release
cargo run --release
```

## 構成

| ディレクトリ | 役割 |
| --- | --- |
| `src/win32/` | Win32 API のラップとウィンドウ管理 |
| `src/graphics/` | DirectX 11 / Direct2D による描画エンジン |
| `src/ui/` | UI コンポーネントと入力処理 |
| `src/settings/` | 設定の永続化と管理 |
| `src/tray/` | システムトレイアイコン |
